# byJoey/cfnew 每日同步镜像

本仓库每日自动同步上游 [byJoey/cfnew](https://github.com/byJoey/cfnew)，始终保持最新版本。

## 使用方法

Fork 本仓库，即可获得一个会自动跟进上游更新的副本，无需手动维护。

> [!IMPORTANT]
> Fork 后请务必前往你仓库的 **Actions** 选项卡，手动启用 GitHub Actions，否则不会自动同步上游更新！

## 项目说明

请参阅上游仓库 [byJoey/cfnew](https://github.com/byJoey/cfnew) 获取完整的部署教程、环境变量说明及使用文档。
